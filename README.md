# Xi Ao Mi Assistant

Voice-controlled Android assistant that responds to "Xi ao mi" wake word.

## Features

- 🎤 Wake word detection: "Xi ao mi"
- 📱 App launcher: Telegram, Zalo, TikTok, Facebook, YouTube
- 📸 Take photos
- 🔊 Volume control (increase/decrease)
- 🔓 Screen unlock
- 🗣️ Text-to-speech feedback

## Installation

1. Download APK from Releases
2. Enable "Unknown sources" on your Android device
3. Install the APK
4. Grant all permissions when prompted
5. Open the app and let it run in background
6. Say "Xi ao mi" to activate

## Usage

After installation:
1. Say "Xi ao mi" to wake up the assistant
2. Say commands like:
   - "Mở Telegram"
   - "Mở YouTube"
   - "Chụp ảnh"
   - "Tăng âm lượng"
   - "Giảm âm lượng"

## Requirements

- Android 7.0+
- Microphone
- Internet connection (WiFi or 4G/5G)
